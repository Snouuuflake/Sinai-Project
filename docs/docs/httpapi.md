# API HTTP

Existen 6 endpoints GET, servidos en <ip\>:<puerto\>. De momento todos responden con 200 (OK).

## Endpoints

- **/next-open-media**: Intenta abrir el siguiente archivo multimedia.
- **/prev-open-media**: Intenta abrir el anterior archivo multimedia.
- **/next-selected-element**: Intenta seleccionar el siguiente elemento proyectable del archivo actual.
- **/prev-selected-element**: Intenta seleccionar el anterior elemento proyectable del archivo actual.
- **/toggle-logo-to-all**: Activa el logo en todos los displays si es que alguno de ellos lo tiene desactivado. De lo contrario, lo desactiva en todos los displays.
- **/project-selected-element-to-all**: Proyecta el elemento seleccionado a todos los displays.
