# Introducción
**Sinai Project** es una aplicación *open source* para la proyección de texto e imágenes, diseñada con iglesias en mente. Algunas de sus capacidades incluyen:

- Creación de letra de canciones, las cuales permiten fácilmente repetir y re-ordenar secciones (Coro, Verso 1, etc)
- Proyección de simultánea de distinto elementos a hasta cuatro ventanas
- Estilos totalmente personalizables para cada pantalla
- Proyección directamente a OBS / Streamlabs
- Control desde un dispositivo móvil (HTTP)
